# Environment Checklist (Offline Deployment)
- [ ] OS: Windows 11 Client / Windows Server 2022+ 
- [ ] Network: Isolated Ethernet network, no internet required
- [ ] Java: JDK 17+ installed and path configured
- [ ] Database: PostgreSQL 14+ or H2 (Embedded) accessible
- [ ] Hardware: RFID Readers/Gates connected via local IP/USB
